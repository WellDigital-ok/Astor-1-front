# **App Name**: Astor's Bash Landing

## Core Features:

- Responsive Invitation Display: Display the provided invitation image, scaling it to fit mobile screens and framing it nicely on desktop with decorative elements like party hats and confetti. Image must be placed at the top of the site, or another very visually prominent location.
- Animated CTA Button: A 'Confirm Attendance' button that uses a subtle animation on hover to invite interaction.
- Confirmation Page: Navigates users to a separate page with a themed background upon clicking the confirmation button.
- Dynamic Guest Form: A form to enter guest names, with an 'Add Guest' link that dynamically adds input fields for additional guests.
- Data Submission to API: Gathers guest information (name, last name) into an array of objects and POSTs it to API_URL/invite.

## Style Guidelines:

- Primary color: Pale Yellow (#FFECB3) to match the lettering from the invitation.
- Background color: Very light blue (#E1F5FE) to match the light background in the invitation, and provide a cheerful overall impression.
- Accent color: Soft pink (#F48FB1) for interactive elements.
- Body and headline font: 'Poppins' (sans-serif) for a friendly, readable style. It is suitable for both headlines and shorter body text.
- Use confetti and party hat icons to reinforce the birthday theme.
- Ensure the invitation image is always centered and scales appropriately across all devices.
- Implement a subtle 'lift' animation on the 'Confirm Attendance' button to indicate it is interactive.
